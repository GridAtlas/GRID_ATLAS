# GRID ATLAS 考察レイヤー（Web実験）

地点リストの本体と、ユーザーが地点同士の関係を考察するために引く線を分離して扱うためのWeb実験仕様です。

## 基本方針

- 地点、メモ、画像は既存の`.gridatlas` place-list documentが本体です。
- 線はアプリ内の考察レイヤーとして保存します。
- 共有時は、地点リストの共有範囲に両端が含まれる線だけを、同じdocumentの任意拡張として同梱します。
- 線を理解しない実装は、地点だけを読み込んでもかまいません。
- 地点リストの表示切替は地点にだけ作用し、線レイヤーの表示は維持します。地点だけを削除した場合も、線は削除せず端点スナップショットから表示を続けます。線を明示的に削除した場合は表示されません。
- 端点スナップショットは端末内の考察レイヤー用データです。共有時は、共有対象の地点IDに両端が解決できる線だけをdocument拡張へ含めます。

## document拡張

拡張キーは`io.gridatlas.lines`です。

```json
{
  "extensions": {
    "io.gridatlas.lines": {
      "version": 1,
      "items": [
        { "id": "line-1", "a": "place-a", "b": "place-b" }
      ]
    }
  }
}
```

`a`と`b`は同じdocument内のplace IDを参照します。線は無向の関係として扱い、同じ2地点を結ぶ重複線は1本に正規化します。

この拡張は、既存のGRID ATLAS v1 Core必須項目を変更しません。対応していない実装では地点だけが表示されます。
