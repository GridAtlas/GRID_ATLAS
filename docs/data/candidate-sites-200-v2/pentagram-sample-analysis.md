## スコアの定義

5地点を中心から見た角度順に並べ、隣り合う5辺を計算する。

`スコア = 五芒星の5本の短い線のばらつき（変動係数[%]） + 内角108°からのズレ（RMS[度]）`

低いほど、辺が揃い、正五角形に近い。近畿五芒星の内訳は次のとおり。

- 五芒星の短い線のばらつき: 3.03%
- 角度のズレ: 5.13°
- 合計: 8.16

サンプル内最良候補の内訳は、短い線のばらつき23.47%、角度のズレ14.82°、合計38.30だった。

## 解釈上の注意

これは全2,535,650,040通りを順位付けした結果ではなく、固定シードによる2,000,000組の再現可能なサンプルである。したがって「全国で1位」「上位何％」とは断定しない。採点式も、旧記事のスコアとは別に、今回のデータで追跡できる単純な基準として定義した。
