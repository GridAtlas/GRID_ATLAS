# スターバックス 日本店舗一覧（2026-08-13取得）

`starbucks-japan-stores-2026.gridatlas` は、スターバックス コーヒー ジャパン公式の店舗検索から取得した、日本全国47都道府県の店舗リストです。

東西分割版として、次の2ファイルも用意しています。

- `starbucks-japan-stores-2026-east.gridatlas`
- `starbucks-japan-stores-2026-west.gridatlas`

分割境界は、東日本を北海道・東北・関東・甲信越・北陸・静岡、西日本を愛知・岐阜・三重・近畿・中国・四国・九州・沖縄としています。都道府県単位で分類しているため、地点の重複や欠落はありません。

## 収録内容

- 店舗名
- 公式店舗検索の店舗ID
- 店舗検索画面が地図表示に使う緯度・経度
- 住所
- 公式店舗ページへのリンク
- 公式検索データに含まれる主なサービス情報

営業時間は変動するため、固定データとして保存していません。

## 出典

- [スターバックス コーヒー ジャパン 店舗検索](https://store.starbucks.co.jp/)
- 取得日: 2026-08-13
- 取得方法: 公式店舗検索が使用する都道府県別の公開検索応答
