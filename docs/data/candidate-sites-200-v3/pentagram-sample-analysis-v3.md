# 近畿五芒星 v3 サンプル計算メモ

## 結果

- 母集団: 200地点
- 背景: 神社建築104地点、寺院建築91地点
- 5地点の全組み合わせ: 2,535,650,040通り
- 実行したサンプル: 2,000,000回（固定シード）
- 近畿五芒星スコア: **8.16**

- サンプル内の最良候補スコア: **28.90**

## スコアの定義

5地点を中心から見た角度順に並べ、五芒星を描くときの2つ先の頂点を結ぶ5本の短い線を計算する。

`スコア = 五芒星の短い線のばらつき（変動係数[%]） + 内角108°からのズレ（RMS[度]）`

近畿五芒星の内訳は、短い線のばらつき3.03%、角度のズレ5.13度、合計8.16。

サンプル内の最良候補は、薬師堂、雷電神社末社八幡宮稲荷神社社殿、佐竹寺本堂、勝常寺薬師堂、護徳寺観音堂で、短い線のばらつき4.89%、角度のズレ24.00度、合計28.90だった。

## 解釈上の注意

これは全2,535,650,040通りを順位付けした結果ではなく、固定シードによる2,000,000回の再現可能なサンプルである。「日本で1位」「上位何％」とは断定しない。採点式も、比較可能性のために今回定義した単純な基準である。
