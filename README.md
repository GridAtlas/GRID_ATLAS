# GRID ATLAS

建物名、地名、地形、道路を表示しない、格子と登録地点だけの地図アプリです。

## 現在のブートストラップ内容

- 格子だけのキャンバス表示
- 緯度経度ベースの地点登録、写真、コメント保存
- 地点同士の線引き
- 地球上の2点間直線距離の計測
- 複数地点の巡回順提案
- 共有URL/クリップボードからの地点登録補助
- 選択地点を外部地図アプリで開く操作
- PWA共有ターゲットと.gridatlasファイル関連付け
- PC向けの距離分析パネル
- 選択線分の交差角・開いた経路の直線度・正多角形／星形多角形（{n/k}）分析と結果コピー
- スマホ向けの地点登録フォーム
- リスト情報はLocalStorage、画像BlobはIndexedDBへローカル保存
- 結界モード（z=18タイルの結界石と結界線をローカル記録）
- .gridatlasのURL・ドラッグ＆ドロップ・ファイル関連付けインポート
- 地点選択のクイック共有（.gridatlasファイル）
- リスト行から位置情報・メモ・画像・考察線を含む.gridatlasファイルを共有／書き出し
- 共有URL・.gridatlasへの考察線レイヤー同梱（対応外の実装では地点だけを表示）
- 画像を含む.gridatlasエクスポートと重複インポート防止
- 依存パッケージなしのローカル開発サーバー

## 起動

```powershell
npm run dev
```

既定では `http://127.0.0.1:5177/` で起動します。

## 検証

```powershell
npm run check
```

## Web版バージョン

現在のWeb版は `0.1329` です。4桁の小数で、更新規模を次のように管理します。

- `+0.0001`: バグ修正、小さな表示・文言調整
- `+0.0010`: 小〜中規模の機能追加、操作変更
- `+0.0100`: 大きな機能群、開発段階の区切り
- `+0.1000`: ユーザーが明示的に意思決定した場合のみ。0.1台の更新には自動で到達しない。`1.0000`は2027年1月予定の正式公開

更新時は `npm run version:web -- --kind patch|feature|milestone` を実行すると、Web版表示・README・Service Workerキャッシュ番号をまとめて更新できます。

## 注意

この初期版は地球上の緯度経度に対応したプロトタイプとしてブラウザ内に保存します。Googleマップ等の短縮URLだけでは、ブラウザ単体で展開できない場合があります。スマホとPC間の自動同期、認証、クラウド写真ストレージは、次フェーズでAPIとデータベースを追加して実装します。
